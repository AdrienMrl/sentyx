# Sentyx mobile mockup

Interactive React design lab for validating the mobile product language. It includes three switchable directions—**Evidence Archive**, **Camera Console**, and **Quiet Companion**—with a linked event feed and detail view for each. Open any event to see how that design handles Gemini analysis, evidence timelines, severity, and full-quality downloads.

```sh
cd mobile
npm install
npm run dev
```

Open `http://localhost:5173`. The prototype uses a phone frame on desktop and fills the viewport on mobile.

The external design brief is in [`CLAUDE_DESIGN_PROMPT.md`](./CLAUDE_DESIGN_PROMPT.md).
